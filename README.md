# SaaS Pricing Table Component

A modern, responsive three-tier SaaS pricing component built with semantic HTML5, CSS Grid/Flexbox, and Vanilla JavaScript.

## Features
- **Interactive Billing Toggle:** Switch seamlessly between monthly and annual billing with a 20% discount calculation.
- **Three Tier Architecture:** Starter, Professional (highlighted with glowing gradient badge), and Enterprise plans.
- **Responsive Layout:** 3-column desktop layout that collapses gracefully into a clean stacked view on mobile.
- **Micro-Interactions:** Subtle hover lifts, button active states, and animated pricing transitions.
- **Custom Design System:** CSS variables for consistent dark-mode styling and Inter typography.
